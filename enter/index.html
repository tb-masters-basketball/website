Unlisted: no nav entry, and (like every page) noindex. It is the one page that needs JavaScript (see CLAUDE.md). Everything about the sheet's shape comes from sheet-spec.json, which the deploy writes next to this page with `scoresheet.py --spec`; the season's teams, players, schedule and file list come from data/, which build_stats.py writes. assets/js/enter.js builds the sheet from both, and assets/js/sheet-rules.js (the Python rules, ported) checks it as you type. {%- endcomment -%}
